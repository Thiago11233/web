Protocolo HTTP

Voltar

O HTTP é o protocolo responsável pela comunicação entre navegador e servidor.

Cliente e Servidor

Cliente é o navegador. Servidor é o computador que hospeda o site.

Requisição e Resposta

O navegador envia uma requisição e o servidor devolve uma resposta.

Métodos

GET

Solicita informações.

POST

Envia informações.

Exemplo de Requisição

GET /index.html HTTP/1.1
Host: exemplo.com

Exemplo de Resposta

HTTP/1.1 200 OK
Content-Type: text/html

Códigos HTTP

  • 200 - Sucesso.
  • 301 - Redirecionamento.
  • 400 - Requisição inválida.
  • 403 - Acesso proibido.
  • 404 - Página não encontrada.
  • 500 - Erro interno.
